## 项目背景

这是 COMP5423 的固定语料检索 Agent 项目。作业指南指定通过 API 使用 **原版 DeepSeek‑V4‑Flash**，允许提供相同模型与功能的其他服务商。优先查找明确固定到原版 GA 修订 **DeepSeek‑V4‑Flash‑0731** 的可调用部署。服务商的模型 ID 可以不同，但要有官方说明能把该 ID 对应到同一原版模型。

截至 2026-11-15（香港时间），**DeepSeek 官方 API 上的原版 DeepSeek‑V4‑Flash 已下架**。`api.deepseek.com` 仍接受旧请求名 `deepseek-v4-flash`，实际由 **DeepSeek‑V4.1‑Flash‑1017** 执行，官方目前使用的模型名为 `deepseek-flash`。这个路由可用于本项目的兼容开发测试。课程正式运行需要原版模型的可核查服务。确认任何候选时都要检查实际路由和固定版本，旧名字或一次 HTTP 200 只能说明请求获响应。[DeepSeek 官方模型与价格说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)
